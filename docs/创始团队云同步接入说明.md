# 创始团队 · 进销存云同步接入说明

通用进销存系统已部署云同步，**创始团队各成员**用自己的电脑登录同一账户，共享同一套数据。

## 一、云服务器信息

| 项 | 值 |
|----|-----|
| 服务器 | 腾讯云 43.128.20.39（Ubuntu 22.04） |
| 云同步地址 | http://43.128.20.39（80 端口，Caddy 反代） |
| 安装包下载 | http://43.128.20.39/updates/inventory-system-setup-0.2.0.exe |
| 自动更新源 | http://43.128.20.39/updates/ |
| 服务 | cloud-server（pm2 常驻，开机自启） |
| 数据目录 | /opt/inventory-cloud/data |
| 加密 | AES-256-GCM 端到端加密 |

## 二、创始人接入（3 步）

### 第 1 步：下载安装包

浏览器打开安装包下载链接，或用 U 盘/网盘拷贝：

```
http://43.128.20.39/updates/inventory-system-setup-0.2.0.exe
```

（117MB，双击安装）

### 第 2 步：启动 → 登录门

1. 安装完成后打开软件
2. **首次启动会弹出「登录 / 注册」门**（可跳过，但跳过是只读演示模式）
3. 点「登录」标签

### 第 3 步：登录团队账户

| 账户 | 密码 | 说明 |
|------|------|------|
| 创始团队 | sync2026 | 团队共用账户，所有人共享一份数据 |

1. 输入账号 `创始团队` + 密码
2. 点「登录（绑定本机）」
3. 登录成功 → 数据自动同步到云端 → 各成员数据互通

> 想用独立数据？在登录门点「注册」创建自己的账户即可（各自数据互不影响）。

## 三、日常操作

| 操作 | 方法 |
|------|------|
| 自动同步 | 登录后自动：启动 2 秒后上传、数据变更 15 分钟内自动同步 |
| 手动同步 | 侧边栏「账号」→ 立即同步 |
| 云端备份 | 侧边栏「账号」→ 云端备份（保留 30 份） |
| 恢复数据 | 侧边栏「账号」→ 云端备份 → 选日期恢复 |
| 手机远程看店 | 登录后「账号」页扫二维码，或开 http://43.128.20.39/v/<token>#key= |
| 换电脑/重装 | 新电脑装好登录同一账户 → 云端备份恢复 |
| 更新版本 | 设置 → 检查更新 → 自动下载安装新版 |

## 四、数据安全

- **端到端加密**：AES-256-GCM，密钥由「账户密码 + 服务器盐」派生，密钥永不上传
- **服务器只见密文**：管理员也无法解密你的数据
- **多设备互通**：所有设备输入同一密码 → 派生同一密钥 → 互解
- **本地 + 云端双备份**：本地每日自动 + 云端 30 份轮换

## 五、故障排查

| 问题 | 解决 |
|------|------|
| 连不上 43.128.20.39 | 检查网络；服务器 pm2 status inventory-cloud 是否 online |
| 登录失败 | 确认账号「创始团队」、密码 sync2026（至少 6 位） |
| 数据没同步 | 账号页点「立即同步」；确认已登录 |
| 游客模式用不了功能 | 写操作被只读拦截属正常；登录账号后恢复 |
| 检查更新没提示 | 确认装的是通用版（非渔具版）；版本号已递增 |
| 忘了密码 | 联系管理员（服务器 /opt/inventory-cloud/data/accounts.json） |
