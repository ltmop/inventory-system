# 前端视觉升级计划 · 渔具风格

> **目的**：功能（里子）已齐，视觉（面子）不够高级。升级为**渔具店气质**，不套通用模板。
> **原则**：抄"面子"不换"里子"——只改视觉层（CSS/组件样式），不动业务逻辑。
> **依据**：GitHub 调研（shadcn 模板 + motion-primitives + React Bits）+ 手机端「阿东渔具」原型设计语言（纸感/印章/贴纸键）在桌面端的延伸。

---

## 一、渔具风格定调（先说清楚"什么叫渔具风格"）

**不要**：通用管理后台的紫/粉渐变科技感、霓虹光效。

**要**：把**老渔具店的质感**和**现代效率工具**结合——像走进一家高端钓具店：

| 设计元素 | 具象 | 用在哪 |
|---------|------|--------|
| **深海洋蓝** | 侧边栏、主按钮（保留现有深海蓝，深化） | 全局骨架 |
| **湖水青** | 成功/在库/可用态 | 徽章、状态 |
| **沙滩金** | 强调/预警的柔和版 | 售价、重要数字 |
| **礁石墨** | 文字、边框（深灰蓝） | 正文、表格线 |
| **纸米黄** | 卡片底色（浅水色 `#f2f6f9` 替代蓝灰） | 卡片、内容区 |
| **印章徽章** | 状态用"盖章"感（红圆章=预警、绿方章=正常） | 状态列 |
| **鱼/波浪** | 侧边栏 logo 徽章、空状态插画 | 品牌记忆点 |

**一句话**：深海蓝的骨架 + 水色的卡片 + 印章的反馈——让老板一眼知道"这是渔具店用的工具，不是通用软件"。

## 二、设计 Token 改造（`src/index.css`）—— 一切的根

现状：已有深海蓝品牌色 + 三级阴影 + `@custom-variant dark`（未启用）。

| # | 改动 | 说明 |
|---|------|------|
| 1 | 扩展品牌色板 | brand-500 保持 `#2563eb` 深海蓝；补 `lake-*` 湖水青、`sand-*` 沙滩金、`reef-*` 礁石墨 |
| 2 | 背景升级 | 主背景从纯 `#e8eef6` 改为浅水色渐变 `#f2f6f9 → #e8eef6`，像水面微光 |
| 3 | 卡片圆角/阴影 | 保持三级投影，圆角统一 `--radius`；hover 上浮已有，强化 |
| 4 | **启用暗色模式** | 补 `:root.dark` token：深蓝黑底 `#0f1b2d` + 卡片 `#17263c`，一键切换 |
| 5 | 印章样式 | 新增 `@utility seal-red / seal-green` 印章徽章工具类 |

| 改动 | 效果 |
|------|------|

### 3.5 状态徽章（`ui/badge.tsx`）——印章感
| 状态 | 现状 | 升级为 |

| 低库存 | 红字 | **红圆章**（预警感） |

### 3.6 图表（各页面 recharts）——海洋配色
| 改动 | 效果 |
|------|------|
| 饼图/柱图配色 | 从默认色板换成**海洋系**：深海蓝、湖水青、水草绿、沙滩金 |

### 3.7 空状态 + 加载（全站）
| 改动 | 效果 |

| 印章弹出 | 结账"收讫"、入库"已入库"印章动画（手机端已有，桌面端确认弹窗可复用思路） |

### 3.9 暗色模式（可选，最后做）
| 改动 | 效果 |
|------|------|
| 全局暗色 | 深蓝黑底 + 卡片深蓝灰，老板打烊后不刺眼 |

## 四、明确不做（防"乱做"）

| 不做 | 原因 |
|------|------|
| 换框架（Next.js） | 伤筋动骨，违背"抄面子不换里子" |
| 引 Ant Design / Element UI | 和 shadcn 冲突，样式打架 |
| 大面积渐变/霓虹/玻璃拟态 | 不是渔具店气质 |
| 手绘/卡通风格 | 要"高级的渔具店"，不是"童趣" |
| 每页改布局 | 布局已合理，只提升质感，不重排功能 |
