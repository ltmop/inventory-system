## 三、催办话术（可直接复制给店长/店员）

> **【必做】从今天起，店里所有买卖都走系统开单，当天录完**
>
> 之前系统里只有一次性的建仓库记录，**一笔真实成交都没有**。没有真实流水，报表、毛利、清仓建议、定价建议全是空转，做出来也没法用。
>
> **只要求 3 件事，每天闭店前完成：**
> 1. **卖出就开单**：成交当场在系统开单，**必须填售价**（不填售价这笔在系统里等于没卖）；扫码价要和标签价一致。
> 2. **进货就入库**：到货当天入库，有保质期的**一定填到期日**（现在 337 个批次一个到期日都没有，临期预警是瞎的）。
> 3. **打烊对账**：报表看当天营业额，和实收现金比一下，差超过 2% 记一笔原因。
>
> **最低启动量：连续 3 天、每天至少 5 笔带售价的开单**，先把数据通道打开；之后再补足 14 天完整清单（A~D 全项）。

## 五、验收怎么核（不用人肉对数，一条命令）

开发侧每次收尾用只读命令复验（不改库）：

```powershell
cd C:\Users\Administrator\Desktop\库存管理\AI智能管理进销存系统
node scripts/inv-analytics.mjs overview            # 今日/本月营业额
node scripts/inv-analytics.mjs first-sale          # 首单是否成立
node scripts/inv-analytics.mjs raw --sql "SELECT COUNT(*) AS priced FROM transactions WHERE type='out' AND selling_price IS NOT NULL"
node scripts/inv-analytics.mjs clearance           # 有流水后清仓引擎才会出 P0
node scripts/inv-analytics.mjs pricing             # 有成交价后定价引擎升级为强口径
```

**达标信号（任一出现即说明通道打开了）**：
1. `first-sale` 从「未出首单」变为已成交；
2. `type='out' AND selling_price IS NOT NULL` 的计数 **> 0**；
3. `overview` 的今日营业额 **≠ 0**。
