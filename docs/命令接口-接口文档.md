## 一、三条通道（同一套命令，三种入口）

| 通道 | 入口 | 鉴权 | 适用 |
|---|---|---|---|
| **IPC** | 渲染进程 `window.fi.invoke('<命令名>', <参数>)` | Electron contextIsolation + `preload.cjs` 白名单 | 桌面界面、命令台 |
| **HTTP 通用** | `POST /api/command`，体 `{"name":"<命令名>","params":{...}}` | `x-token` 或 `?token=`（与整站同一套）；写命令另受只读令牌限制 | 手机端、中央库、外部 Agent |
| **HTTP 传统** | `POST /api/invoke`，体 `{"channel":"<命令名>","payload":{...}}` | 同上 | 既有手机端/桌面中心库模式（兼容保留） |
| **CLI** | `scripts/inv.mjs`（云同步）、`scripts/inv-analytics.mjs`（经营分析） | 各自配置 | 命令行、脚本、定时任务 |

> 自省：`GET /api/commands`（全集/`?group=`/`?q=`）、`GET /api/commands?name=<命令名>`（单条详情）；IPC 侧对应 `commands:list` / `commands:describe`。

### 调用示例

```bash
# HTTP 通用入口（推荐给外部集成；token 见「设置  手机看店」或中心库状态）
curl -s -X POST http://127.0.0.1:3200/api/command \
  -H 'content-type: application/json' -H 'x-token: <TOKEN>' \
  -d '{"name":"data:loadAll","params":{}}'

# 先查有哪些命令 / 某条命令怎么调
curl -s http://127.0.0.1:3200/api/commands?q=库存 -H 'x-token: <TOKEN>'
curl -s 'http://127.0.0.1:3200/api/commands?name=product:create' -H 'x-token: <TOKEN>'
```

```js
// 桌面渲染进程（命令台走的就是这条）
await window.fi.invoke('product:create', { name: '红茶', sku_code: 'SKU-1', cost_price: 10 })
```

## 四、改动命令后怎么让文档跟上

```bash
# 1) 改代码（main.js 的 handle / server.js 的 INVOKE_CHANNELS / commands/*.js 的 JSDoc）
# 2) 重新抽取注册表
node scripts/command-surface.mjs --emit-registry
# 3) 重新生成文档
node scripts/gen-command-doc.mjs
# 4) 校验（不一致会 exit 1，可挂进断言闸门）
node scripts/command-surface.mjs && node scripts/gen-command-doc.mjs --check && node scripts/verify-command-api.mjs
```

> 顺带提醒：新增 IPC 命令时，**别忘了 `electron/preload.cjs` 的 `CHANNELS` 白名单**  
> 2026-09-13 就踩过一次：通道注册了但没放行，前端调用直接报「未知通道」。
> `node scripts/command-surface.mjs` 会把这个不一致列出来。
