# 功能代码地图（AI智能管理进销存系统）

> **目的**：按功能找代码、微调整。想改哪个功能，先查这张表定位到文件。
> **结构**：前端 = `src/`，后端 = `electron/`，云端 = `cloud-server/`，手机端 = `electron/mobile/`

## 五、后端命令层内部结构（electron/commands/）

想改业务逻辑，去对应功能模块文件。共享工具在 `helpers.js`（改了全局生效，慎改）。

| 模块 | 职责 | 主要导出 |
|------|------|---------|
| `helpers.js` | 共享工具：校验/事务/编号/常量 | assert*, inTransaction, now, today, PRODUCT_STATUSES 等 |
| `products.js` | 商品增删改、批量改价改状态 | createProduct, updateProduct, deleteProduct, batchUpdateProducts |
| `inbound.js` | 入库 | createInbound |
| `outbound.js` | 出库/收银/退货/换货（FIFO） | confirmOutbound, confirmCheckout, createReturn, createExchange |
| `suppliers.js` | 供应商 + 对账 | createSupplier, updateSupplier, deleteSupplier, supplierStatement |
| `customers.js` | 客户 + 赊账 + 还款 + 对账单 | listCustomers, recordPayment, customerStatement |
| `stocktake.js` | 盘点 | createStockTake, submitStockTake |
| `purchase.js` | 采购订单 | createPurchaseOrder, receivePurchaseOrder |
| `priceTier.js` | 多级定价 | setPriceTier, getPriceTiers |
| `reports.js` | 统计：低库存/今日收款/临期 | lowStockProducts, todayPaymentSplit, expiringProducts |
| `expenses.js` | 支出 | createExpense, listExpenses |
| `onboarding.js` | 新手引导 + 清空演示数据 | resetDemoData, onboardingStatus |
| `import.js` | 批量导入 | importBatch |
| `audit.js` | 操作日志查询 | auditLog |
| `catalog.js` | 全量数据加载 | loadAll |
