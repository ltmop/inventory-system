# MCP 接入配置（2026-09-23）

> 一句话：**MCP 这层没有新能力**，它只是把本系统已有的命令注册表接到标准插座上。
> 设计与取舍见 `docs/设计-资金账户与MCP外壳-20260922.md`。

## 一、先跑一次自检（不接客户端也能验）

```powershell
cd "D:\B5-进销存数据\库存管理\AI智能管理进销存系统"

# 连生产中心库（令牌在桌面端「设置 → 手机看店」或中心库那台机器的 data/server-token.txt）
node scripts/mcp-server.mjs --url https://app.junchengzn.com --token <中心库令牌> --selftest

# 连本机（自动读 %APPDATA%\fishing-inventory\server-token.txt，默认 127.0.0.1:3200）
node scripts/mcp-server.mjs --local --selftest
```

预期输出形如：

```json
{ "ok": true, "url": "https://app.junchengzn.com", "allowWrite": false,
  "tools": 108, "sample": ["ai_analyzePhoto", "ai_chat", "ai_correctTerm"], "docOk": true }
```

`tools` 是**只读命令条数**（写命令默认不暴露）。没拿到数字就是：令牌不对 / 地址不对 / 网络不通。

## 二、接 Claude Desktop

编辑 `%APPDATA%\Claude\claude_desktop_config.json`（没有就新建）：

```json
{
  "mcpServers": {
    "inventory": {
      "command": "node",
      "args": [
        "D:\\B5-进销存数据\\库存管理\\AI智能管理进销存系统\\scripts\\mcp-server.mjs",
        "--url", "https://app.junchengzn.com",
        "--token", "<中心库令牌>"
      ]
    }
  }
}
```

保存后**完全退出并重开** Claude Desktop（托盘里也要退）。它的工具列表里应出现 `ai_*`、`report_*`、`fund_overview` 等。

## 三、接 Cursor / 其它支持 MCP 的客户端

同样是「command + args」两段，命令行行为与上面完全一致：

```
node <仓库绝对路径>\scripts\mcp-server.mjs --url https://app.junchengzn.com --token <中心库令牌>
```

- 想按前缀收窄工具面：再加 `--group report`（只暴露报表那批）。
- **要不要开写命令**：默认不开。确实需要时加 `--allow-write`（或设环境变量 `FI_MCP_ALLOW_WRITE=1`）——
  开了就等于把"改账/改库/改文件"的能力交出去，**默认值故意是关的**。

## 四、能用的工具

- 业务命令：`GET /api/commands` 里的每一条，工具名 = 命令名把 `:` 换成 `_`
  （如 `report:lowStock` → `report_lowStock`）。参数统一放在 `params` 对象里：
  ```json
  { "name": "report_lowStock", "arguments": { "params": {} } }
  ```
- 两个自省工具：
  - `inventory_command_doc` —— 查命令清单 / 单条说明（`{name}` 或 `{q}` 或 `{group}`）
  - `inventory_agent_guide` —— 取接入说明（鉴权、入口、CLI 路径）

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动就退出、什么都没输出 | 缺令牌：给 `--token`，或设 `FI_TOKEN`，或用 `--local`。stderr 会写明 |
| `tools` 数量很少 | 用了 `--group` 收窄，或客户端缓存了旧清单（重开客户端） |
| 客户端里看不到工具 | 客户端只认**自己配置文件里**的 MCP server；确认绝对路径没写错（Windows 里反斜杠要写 `\\`） |
| 想调写命令但报未知工具 | 默认只暴露只读；加 `--allow-write` 重开 |
| 令牌从哪来 | 中心库那台：`/opt/inventory-app/data/server-token.txt`；桌面端：「设置 → 手机看店」里也能看到 |
