# 通用进销存 CLI 使用指南（老板版）

本工具让**一个进销存账户在多台电脑上同时使用**，数据自动共享。不用会编程，照着下面做就行。

---

## 一、我为什么要用它？

- **多台电脑**：店里收银台一台、办公室一台，两边数据一样
- **换电脑不丢数据**：新电脑登录同一账户，云端备份一键恢复
- **手机看店**：绑定后手机打开链接，随时看今天卖了多少钱
- **不怕电脑坏**：每天自动云端备份，坏了换台电脑恢复即可

---

## 二、第一次用（管理员做一次）

### 1. 启动云服务器（一台电脑上做，这台就是云端）

双击 `cloud-server/start-cloud.bat`，看到「云备份服务已启动」即成功。
记下这台电脑的 IP（设置 → 网络 → 查看）和端口（默认 3100）。

> 想让公网访问（店外也能同步），把服务器部署到云主机/域名，或用内网穿透。

### 2. 每台电脑接入

打开命令行（开始菜单搜 cmd），进入进销存目录：

```bash
cd C:\Users\你的用户名\Desktop\库存管理\AI智能管理进销存系统

# 指向云服务器（每台电脑第一次都要设）
node scripts/inv.mjs config --server http://服务器IP:3100

# 第一台电脑：注册账户（一个店注册一次）
node scripts/inv.mjs register --username 我的店 --password 123456

# 登录绑定本机
node scripts/inv.mjs login --username 我的店 --password 123456
```

### 3. 其他电脑

不用再注册，直接登录同一账户：

```bash
node scripts/inv.mjs login --username 我的店 --password 123456
```

---

## 三、日常操作

### 查看同步状态

```bash
node scripts/inv.mjs status
```

### 手动同步（平时桌面端会自动同步，这个用于手动/脚本）

```bash
node scripts/inv.mjs sync
```

### 手动云端备份（数据保险）

```bash
node scripts/inv.mjs backup
```

### 换电脑 / 电脑坏了，恢复数据

```bash
# 新电脑装好软件后，先登录账户
node scripts/inv.mjs login --username 我的店 --password 123456

# 看看云端有哪些备份
node scripts/inv.mjs backups

# 恢复最近一天的备份
node scripts/inv.mjs restore --date 2026-08-21
```

恢复后打开桌面端软件，数据就是云端那份了。

---

## 四、桌面端操作（不用命令行也行）

打开软件 → 设置 → 云备份 · 远程看店：
- 没登录：切到「登录账户」标签，输入账户密码即可绑定
- 已登录：「立即同步」手动传一次，「云端备份」看/恢复历史备份
- 手机看店：登录后出现二维码，微信扫一扫即看

---

## 五、注意事项

- **密码记牢**：忘了密码需要管理员在云服务器管理页重置
- **账户 = 店**：一个店一个账户，别和别的店共用
- **服务器别关**：云服务器那台电脑要保持开机（或部署到云主机）
- **局域网/公网**：店里电脑用局域网 IP 最快；跨店/外出用公网

---

## 六、常见问题

| 问题 | 解决 |
|------|------|
| 连不上服务器 | 检查服务器是否开机、防火墙是否放行 3100 端口 |
| 登录提示密码不对 | 确认账户名密码（密码至少 6 位） |
| 两台电脑数据不一样 | 分别点「立即同步」，稍等再刷新 |
| 想换店/换账户 | 重新 config --server 指向新服务器，再登录新账户 |
