## 4. 日常操作（运营团队）
| 动作 | 在哪 |
|---|---|
| 开单出库 | 首页「开单」/ 销售 → 扫码或搜SKU → 选数量/价格 → 确认出库 |
| 入库进货 | 首页「入库」→ 扫码/选品 → 填数量/成本 → 入库 |
| 查库存 | 库存查询（SKU/品牌/品类筛选 + 低库存/临期快捷） |
| 盘点 | 库存 → 待盘点 → 逐项核对实盘数量 |
| 报表 | 赚了多少 / 什么最赚钱 / 谁欠我钱 / 什么压着钱 / 日结对账 |
| 看板 | 首页「大屏」→ 经营驾驶舱（实时 KPI + 趋势） |

> 所有操作都在**同一中心库**记账 → 数据即时进数据库，驾驶舱/Base 看板同步刷新。

## 5. 数据流向（自动，无需操作）
```
进销存开单/入库 → 中心库(SQLite)
     ↓ inv-analytics + inv-cockpit-sync（自动/每小时）
驾驶舱数据源(库存经营数据.md) + 首单卡片(业务真实进度.md)
     ↓ sync-workbench（已转自动化，每小时）
Base 经营指标看板 + 飞书群(首单/逾期通知)
```
