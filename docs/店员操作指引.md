# 店员操作指引

> 给店里收银/看店的店员看。照着做，几分钟就会。

## 一、怎么登录（每天开店第一步）

1. 打开软件 → 右上角点 **「未登录」**（人形图标旁）
2. 点 **「登录（店员/老板）」**
3. 输入老板给你的**登录名 + 密码** → 登录

> 登录后右上角会显示你的名字（如「丹丹 / 店员」）。
> 每一笔出库都会记在你名下，月底对账一目了然。

## 二、怎么开单卖货（出库）

### 卖一件货
1. 点左侧 **「销售」→「销售出库」**
2. 扫码枪扫商品条码，或搜索框输商品名
3. 填**数量**和**实际售价**（收多少钱填多少）
4. 点 **「确认出库」**

### 一次卖好几样（批量）
1. 同样进「销售出库」
2. 扫/搜第一个商品 → 点 **「加入清单」**
3. 继续扫/搜第二、第三个……全加进清单
4. 清单里核对数量、价格
5. 点 **「去开单」→ 确认** → 一次完成

> 一单最多 50 种商品，收银台会自动算总额。

## 三、店里没录库存的货能卖吗？

能。货架上有货但系统里没录库存时：

1. 按正常流程开单
2. 提示「库存不足」时 → 点 **「无库存也出库」**
3. 照常成交，系统记「负库存」提醒老板补录入库单

> 这是给"货到了还没录"的情况兜底，正常有库存的直接卖就行。

## 四、常见问题

| 问题 | 解决 |
|------|------|
| 不知道登录名/密码 | 找老板在「设置 → 员工账号」里建，或直接问老板 |
| 扫码没反应 | 确认扫码枪连的是这台电脑（USB 即插即用） |
| 搜不到商品 | 换关键词试试（品牌/型号/条码都能搜） |
| 卖错数量/价格 | 已确认的出库不能改，找老板在「操作日志」看记录，或报损/退货处理 |
| 想退出登录 | 右上角点你的名字 → 「退出当前身份」 |
